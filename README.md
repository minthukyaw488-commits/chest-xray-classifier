## How It Works

Chest X-Ray Image

↓

ConvNeXt-Tiny CNN

(custom trained on 5,216 images)

↓

NORMAL or PNEUMONIA + confidence score

↓

LLaMA 3.3 70B (via Groq API)

↓

Plain English explanation + interactive Q&A

## Features

- Pneumonia detection from chest X-ray images
- 88.46% test accuracy on the Kaggle chest X-ray dataset
- Plain English explanation of results generated by LLaMA 3.3
- Interactive follow-up Q&A about the diagnosis
- Honest documentation of domain shift between train/test populations

## Setup & Installation

**1. Clone the repo**
```bash
git clone https://github.com/minthukyaw488-commits/chest-xray-classifier.git
cd chest-xray-classifier
```

**2. Install dependencies**
```bash
pip install torch torchvision groq python-dotenv pillow
```

**3. Get a free Groq API key**

Sign up at [console.groq.com](https://console.groq.com) — no credit card required.

**4. Create a .env file**

GROQ_API_KEY=your-groq-key-here

**5. Run the assistant**
```bash
python3 medical_ai.py
```

## Model Details

- Architecture: ConvNeXt-Tiny (pretrained on ImageNet, fine-tuned)
- Classes: NORMAL, PNEUMONIA
- Training set: 5,216 chest X-ray images
- Test accuracy: 88.46%
- Framework: PyTorch

### Known Limitation

A domain shift exists between the training and test populations in this dataset — the training images were collected from a different patient group than the test images. This is documented honestly and is a known characteristic of the Kaggle chest X-ray dataset. Real-world performance may vary.
